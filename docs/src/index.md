# PolyOrigin.jl

**Haplotype reconstruction in multi-generation tetraploid (or diploid) pedigrees**

### Features

- Apply to multi-generation pedigrees, including connected F1 populations
- Apply to SNP array and GBS data
- Account for preferential pairing and quadrivalent formation in polyploid
- Account for allelic bias and over-dispersion in GBS data

### Installation
From the Julia (>v1.12.0, 64-bit) REPL model, type `]` to enter the Pkg REPL mode and run

```pkg
add https://github.com/chaozhi/PolyOrigin.jl
```
